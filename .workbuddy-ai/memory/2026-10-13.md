## 三、发现的 Bug 与修复（9 项已修）

### B1. Hero 描述类名冲突（我上次引入）
`sm:text-base sm:text-lg` 同时存在 → Tailwind 输出顺序决定胜者，行为不确定。
**修复**：`Hero.tsx` 删掉 `sm:text-base`。

### B2. ESLint 2 个 error：Beams 函数超长
`max-lines-per-function: 150` 被违反（186 / 177 行），另有 `complexity: 19`。
CODE_STYLE.md 声明了「豁免流程」，但 `eslint.config.mjs` 里**根本没有 `LARGE_FILE_ALLOWLIST`**，豁免清单表也是「暂无」。
**修复**：
- `eslint.config.mjs` 新增 `LARGE_FILE_ALLOWLIST` 常量 + 对应 override
- `docs/CODE_STYLE.md` 豁免清单表登记 Beams.tsx（458 行，附理由）

### B3. 幽灵依赖
`eslint.config.mjs` 直接 import `@typescript-eslint/parser` 和 `eslint-plugin`，但 `package.json` **没有声明**，靠 `eslint-config-next` 的传递依赖侥幸可用。
**修复**：`package.json` 显式加入 `@typescript-eslint/parser` / `eslint-plugin` ^8.71.1。

### B4. 无 JS / 减少动效 / 打印时内容不可见 ⭐
SSR HTML 里有 **22 个元素**带 `style="opacity:0;transform:translateY(24px)"`（InView 的初始态）。
→ JS 不可用、`prefers-reduced-motion`、打印/导出 PDF 时，这些内容**永久不可见**，直接违背项目「特效全挂也能读」的核心原则。
**修复**（三处兜底，均为 CSS `!important` 覆盖内联样式）：
- `InView.tsx` 根节点加 `data-inview` 属性
- `globals.css`：`@media (prefers-reduced-motion: reduce)` + `@media print` 各加 `[data-inview]{opacity:1!important;transform:none!important}`
- `layout.tsx`：`<noscript><style>...</style></noscript>`

### B5. 瞬时跳转导致区块永久不可见 ⭐
IntersectionObserver **只报告相交状态变化**。整页截图 / `scrollTo` 到底 / print 这类**瞬时跳转**会把区块整个「跳过」，IO 从未观察到 → 内容永远停在 opacity:0。
实测：跳到底后 22 个元素里有 4 个仍是 0；`#gates` 标题区一直空白。
**修复**：`config/motion.ts` 的 `VIEWPORT` 加 `margin: '100000px 0px 0px 0px'` —— 把「视口上方」整片纳入观察区，元素一旦落到视口上方即判定为已进入。视口下方行为不变，滚动观感不受影响。
**验证**：修复后瞬时跳到底，22 个元素**全部 opacity=1**。

### B6. 移动端水平溢出 66px ⭐⭐
390×844 下 `document.documentElement.scrollWidth = 441`，页面可左右滑动。
根因：`Start.tsx` 的 `grid` 子项默认 `min-width: auto`，被终端代码块里那条长 `git clone https://...` URL 撑开（`#start` 宽 375 但 `scrollWidth=441`）。
**修复**：两个网格子项加 `min-w-0`。

### B7. DecryptedText 无障碍缺失（我上次引入）
上次为修「标题重复」移除了 `sr-only` 原文，导致读屏软件会逐字朗读标题。
**修复**：加回隐藏原文 span，但改用 **inline style** 而非 `.sr-only` 类 —— 即使样式表加载失败也不会退化成可见文本（正是当初重复显示的根因）。

### B8. og:url / metadataBase 指向错误
`metadataBase` 和 `og:url` 都指向 GitHub 仓库地址，而不是站点本身。
**修复**：`types/site.ts` + `config/site.ts` 新增 `url` 字段，`layout.tsx` 改用 `siteConfig.url`，并补 `alternates.canonical`。

### B9. 缺 favicon + Beams 开发环境黑屏
- `public/` 为空、无 favicon → 新增 `src/app/icon.svg`（薄荷绿漏斗，呼应「岗位筛选」）
- `Beams.tsx` cleanup 调用了 `WEBGL_lose_context.loseContext()`。React StrictMode 在开发环境会「挂载→清理→再挂载**同一个 canvas**」，第二次挂载拿到的是已丢失的上下文 → **画面全黑**。
  **修复**：移除 `loseContext()`，改由浏览器在 canvas 移除后回收。

### 为什么保留 Beams 而不是删掉

用户要求「所有改动需支持回滚」。Beams 有完整的 458 行渲染管线，直接删掉是破坏性的；
改为「配置切换」既满足换效果，又保留退路，且不算死代码（仍被引用）。

### ⚠️ 手写 shader 的调参教训（下次别再踩）

| 版本 | 参数 | 结果 |
|---|---|---|
| v1 | 5 层叠加不归一化 + `exp(-d²·24)` + intensity 1.15 | **过曝成白团，标题完全被盖住** |
| v2 | `acc/=5` + `exp(-d²·70)` + intensity 0.5 + 左侧压暗 0.16 | **过度修正，极光几乎看不见** |
| v3 ✅ | `acc/=5` + `exp(-d²·45)` + intensity **1.9** + 左侧压暗 0.14 + 光帘偏右(center 0.62) + 暗角 0.45 | 平衡 |

**关键经验**：
1. 多层叠加**必须归一化**（除以层数），否则线性叠加直接爆表
2. 极光要「偏右分布 + 左半屏压暗」，把左半边留给标题 —— 否则文字必被淹没
3. 调 intensity 要**先看归一化后的量级**，凭感觉给值会差一个数量级
4. Hero 底部要加 `from-transparent to-base` 渐隐，否则 canvas 在区块边界硬切

### 新增 React Bits 效果

| 效果 | 实现 | 用在哪 |
|---|---|---|
| **Blur Text** | `effects/BlurText/` —— 逐词「模糊+下沉+透明」→ 清晰，形成对焦感 | `SectionHeading` 的全部标题 |
| **Border Glow** | 升级 `SpotlightCard` —— 用 mask 把径向渐变裁进 1px 边框，跟随鼠标 | 所有卡片（Features / Platforms / Pace） |

**BlurText 的分词坑**：中文没有空格，`text.split(' ')` 会整段不动。
正确写法：`text.match(/[A-Za-z0-9]+|\s+|[\s\S]/g)` —— 英文/数字整词、空白原样、其余单字。

**降级**：BlurText 每个词都带 `data-inview`，并把 `filter: none !important`
补进 `prefers-reduced-motion` / `print` / `noscript` 三处兜底规则（否则模糊态会残留）。
