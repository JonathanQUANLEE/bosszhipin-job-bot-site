## 💡 为什么需要 JobKoi？

求职最耗人的往往不是面试本身，而是**机械重复的信息筛选与沟通内耗**：

| 传统手动求职的痛 | JobKoi 的解法 |
|---|---|
| **多平台反复横跳**：在各大招聘平台来回切，手动刷新几百次 | **后台协同盯盘**：一次设置求职意向，三大平台后台自动协同寻找合适岗位 |
| **生硬模板已读不回**：千篇一律复制粘贴，在 HR 屏幕停留不足 3 秒 | **自带免费 AI**：作者买单免费提供大模型，根据你的真实简历与岗位定制真诚开场 |
| **虚假外包防不胜防**：满屏培训贷、套路中介与劣质岗位 | **智能排雷避坑**：自动识别并过滤黑名单与劣质企业，只把靠谱机会留给你 |
| **隐私泄露与封号风险**：脚本死板刷单易被封，数据上传云端易泄露 | **100% 本地运行**：拟人化慢速安全巡航，所有数据仅存在你的电脑中，绝不上云 |

## ✨ 核心亮点

### 1. 三大平台，后台同时跑
深度聚合 **BOSS 直聘**、**猎聘**、**前程无忧 51Job**。告别每天数小时的机械盯盘，后台自动为你匹配符合期望的优质岗位。

### 2. 内置免费 AI，拒绝冰冷套路
**完全无需自己购买或配置任何 API Key**。作者免费为大家买单开放高并发大模型，根据你的真实履历与目标岗位定制自然真诚的第一句问候，大幅提高回复率。

### 3. 本地私有，安全防封
像真人一样有条不紊地浏览操作，绝不搞死板高频刷单。你的简历、登录状态与沟通记录全部只保存在你自己电脑的私有数据库中，无云端数据泄露风险。

## 🚀 极速下载与安装

### 推荐方式：下载 Windows 客户端

1. 前往 **[GitHub Releases 官方发布页](https://github.com/JonathanQUANLEE/JobKoi-AI/releases/latest)**；
2. 下载 Windows 安装包（推荐 `.exe` 格式）；
3. 双击极速安装运行即可（首次使用前请确保电脑已安装 Chrome 浏览器）。

### 开发者方式：从源码本地启动

```bash
git clone https://github.com/JonathanQUANLEE/JobKoi-AI.git
cd JobKoi-AI
uv sync
uv run python -m boss_zhipin.tauri
```
